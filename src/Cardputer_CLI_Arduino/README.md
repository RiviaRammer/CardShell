# Installation

- **Board:** M5Stack  
- **Libraries:** LibSSH-ESP32, M5Cardputer (and all required dependencies)

# Setting

- **Partition Scheme:** Huge APP: (3MB No OTA/1MB SPIFFS)  
- **Flash Size:** 8MB(64Mb)  

# Mode

- Press G0 after reset Cardputer

# Notice
- Only support PEM Private Key
```bash
-----BEGIN RSA PRIVATE KEY-----
-----END RSA PRIVATE KEY-----
```
